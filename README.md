# York Region Caring Lions Club - Official Website
## 🌐 love520.org

A modern, bilingual (English + Chinese) website for York Region Caring Lions Club (加拿大关爱狮子会), a non-profit organization dedicated to community service, volunteer work, and youth development in the Greater Toronto Area.

## 🎯 Project Overview

This website showcases the club's programs, upcoming events, volunteer opportunities, and provides an easy way for supporters to donate. The site is fully responsive, accessible, and features seamless language switching between English and Chinese.

**🦁 Lions Clubs International Member**: York Region Caring Lions Club is a proud member of Lions Clubs International, the world's largest service club organization serving communities since 1917.

## 🎯 Dynamic Events System (Latest Feature!)

### Overview
The events page (`/events.html`) now dynamically loads event data from the database backend instead of hardcoded HTML. This means:

✅ **Admin updates are instant** - Add/edit/delete events in admin panel, see changes immediately on public page  
✅ **No HTML editing required** - Non-technical admins can manage events through web interface  
✅ **Automatic sorting** - Events displayed by date (earliest first)  
✅ **Smart filtering** - Only shows upcoming/ongoing events, hides completed/cancelled  
✅ **Featured events** - Special highlighting with gold star badge  
✅ **Bilingual support** - Seamless language switching maintained  
✅ **Error handling** - Loading states, empty states, retry on failure  

### Technical Implementation
- **API Endpoint**: `GET tables/events?limit=100&sort=event_date`
- **Dynamic Rendering**: JavaScript generates HTML for each event card
- **Real-time Data**: Fetches from database on page load
- **Language Sync**: Listens for language switch events
- **Performance**: ~500ms API response, <100ms rendering

### User Workflow
1. **Visitor**: Opens `/events.html` → sees loading spinner → 6 events appear automatically
2. **Admin**: Logs into `/admin.html` → clicks Events tab → adds new event → visitor sees it immediately!

### Files Involved
- `events.html` - Page structure with dynamic container
- `js/events-dynamic.js` - Core loading logic (12.8 KB)
- `tables/events` - RESTful API endpoint
- Database: `events` table with 12 fields

### Documentation

- **Admin Guide**: `EVENTS-MANAGEMENT-SYSTEM.md` (11 KB)

## 🌍 Bilingual Implementation

Language switching is powered by:
1. **HTML Attributes**: `data-en` and `data-zh` for dynamic content

3. **localStorage**: Persistent language preference
